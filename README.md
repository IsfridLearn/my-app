# Andrei Sanchez, Portfolio

My personal portfolio as a 2nd year BSIT student.

Stack: Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Motion, and the Aceternity components used on the site.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Add content

Projects, stack, and certificates are typed arrays at the top of `app/page.tsx`. Add certificate images to `public/certificates`; the Certificates section hides itself when the certificate list is empty.
