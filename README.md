# Andrei Sanchez, Portfolio

My personal portfolio as a 2nd year BSIT student.

Stack: Next.js, React, TypeScript, Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Add content

All text lives in `lib/content.ts`. Anything left empty there does not appear on the page. To replace the portraits, put the new originals in `assets/portraits` and run `node scripts/make-plates.mjs`.
